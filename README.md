# ShareHub
Community Resource Sharing Platform
Developing a full-stack web application using ASP.NET Core Web API, ASP.NET Core MVC, Entity Framework Core and SQL Server.

Designed and implemented RESTful API endpoints for item management and reservations.
Developed an MVC frontend communicating with the API using HttpClient.
Implemented user authentication, role-based authorization and reservation workflows.
Designed relational database entities and relationships using Entity Framework Core.
Implemented business rules to prevent overlapping reservations and unauthorized operations.
Used dependency injection, DTOs and service-based architecture to maintain separation of concerns.

| Component | Technology |
|---|---|
| Backend | ASP.NET Core Web API |
| Frontend | ASP.NET Core MVC |
| Database | Microsoft SQL Server |
| ORM | Entity Framework Core |
| Testing | NUnit, Moq, ASP.NET Core Integration Testing |
| Hosting | MonsterASP |
| CI/CD | GitHub Actions |
| IDE | Visual Studio 2026 |
